DataShield MCP is a privacy‑first AI data preparation toolkit that lets you clean, validate, deduplicate, detect PII/secrets, normalize, and sanitize local datasets directly through MCP‑compatible AI assistants such as Claude Desktop, Claude Code, and Cursor.

All processing happens on your machine — no data leaves your computer, no external APIs are called, and no telemetry is collected. The toolkit is ideal for developers, analysts, students, researchers, and anyone who works with messy CSV, Excel, or JSON files and needs to prepare data safely for sharing, analysis, or machine learning.

Core capabilities include:
- File inspection and profiling
- Duplicate detection (exact and fuzzy)
- PII detection (email, phone, SSN, credit card, regional IDs, etc.)
- Secret detection (API keys, tokens, private keys)
- Sanitization (mask, hash, remove, replace, tokenize)
- Normalization (column names, whitespace, casing, dates, phones, emails)
- Validation (required columns, uniqueness, ranges, allowed values)
- Safe cleaning (trim, standardize empties, drop exact duplicates)
- File conversion (CSV, TSV, JSON, JSONL, XLSX, Parquet)
- Data quality reporting (Markdown, JSON, HTML) with a DataShield Quality Score
- Change preview and sanitized copy creation with timestamps

The free, open‑source edition provides a robust set of tools for everyday data tasks. For users who want extra value, DataShield Pro ($2 one‑time) delivers advanced PII rule packs, premium cleaning recipes, validation templates, 50+ AI workflow prompts, and curated workflow recipes for cleaning, privacy, validation, reporting, and dataset comparison.

DataShield MCP puts you in control of your data — locally, privately, and efficiently.
