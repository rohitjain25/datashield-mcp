# Data Privacy

DataShield MCP processes data entirely on the local machine.

## What Data Is Collected

None. The application does not collect, transmit, or telemetry any data from your files.

## What Data Is Processed

Only the files you explicitly point the tool at. The application reads the file, performs the requested operation, and writes results to new files (unless you specify an output path that overwrites).

## Data Retention

The application does not retain any data after the operation completes. All data resides in memory only for the duration of the processing and is released afterwards.

## Third‑Party Services

The core MCP has no dependencies that make external network requests. Optional premium features may download rule packs, but those are shipped locally.

## Your Responsibilities

- Ensure you have the right to process any data you point the tool at.
- Store sensitive output securely.
- Review the output of sanitization operations before sharing.
